# Contributing

Contributions are encouraged to anyone in SDC who desires to make contributions to bobcat coin.

## Rules

- Changes should be commited into a separate branch based on the feature and merged into main once finished.
- New features should have a well-defined use case.
- Merges are required to be peer reviewed>
- Unreviewed AI code is Prohibited.
- unit tests are required for all files.
- Follow all rust formatting and style guidelines suggested by the rust analyzer extension.
